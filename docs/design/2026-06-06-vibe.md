# Design vibe: friendliest professor of world rhythm

## The feeling

A music classroom run by a curious, warm, slightly eccentric teacher who has spent decades collecting rhythm traditions from everywhere. Hand-feeling without being twee. A 1970s music textbook crossed with a studio sketchbook. Joyful, but not loud. Plain enough that an AuDHD/ESL reader is calm. Decorated enough that a reader who loves design wants to scroll.

NOT: developer playground, AI app aesthetic, brutalist landing page, corporate edtech.

## Palette

Warm + earthy + grounded. Replace the current zinc + lime with paper + terracotta + teal.

| Token | Light | Dark | Used for |
|---|---|---|---|
| `--bg` | `#f7f3e9` (paper cream) | `#0f0e0c` (warm dark) | Page background |
| `--fg` | `#1a1a1a` (ink) | `#f5f1e8` (paper) | Main text |
| `--muted` | `#5e574a` (warm grey) | `#a39e90` (warm grey) | Secondary text |
| `--accent` | `#c2410c` (terracotta) | `#f97316` (orange) | Active, current, hover |
| `--secondary` | `#0d9488` (deep teal) | `#14b8a6` (teal) | Progression, success |
| `--rule` | `#d6cdb6` (paper rule) | `#2a2620` (subtle warm) | Borders, dividers |

The lime green stays only in the favicon (it already exists, replace later if needed).

## Typography

Three families. No more.

- **Display**: **Fraunces** (variable serif). Italic optical-size variant for personality. Used for h1 + h2 on hero areas.
- **Body**: **Geist** (already loaded). Used for paragraphs and UI text.
- **Mono**: **Geist Mono** (already loaded). Used for code blocks and the tree ASCII rendering.

H1 in Fraunces semibold, optical-size 144 if available. H2 in Fraunces medium italic, smaller. H3 onwards in Geist semibold.

## Microinteractions

All gated on `motion-safe:` Tailwind variants. Honour reduce-motion.

- **Mark-read**: a tiny burst of three accent-colored dots that float up and fade. ~400ms.
- **Correct answer**: the answer text gives a single small "nod" (translateY 2px then back). ~250ms.
- **Tree row hover**: subtle background tint + 1px horizontal nudge of the prefix glyph.
- **Bottom playground bar open**: spring-easing slide-up. CSS transition with cubic-bezier(0.34, 1.56, 0.64, 1) for a tiny overshoot.

## Mascot

An abstract face: two dots for eyes, a single curling moustache, a beret. Drawn in ~12 SVG path commands. Sized 24px to 240px. Colored by `currentColor` so it inherits context.

Used in:
- 404 page (the only one)
- Empty review state ("nothing due, M. Maestro is napping")
- Final review success
- Footer (small)

NOT in headers or as decoration on every page. Sparingly.

## Stage icons

Each of the 9 stages gets a tiny SVG glyph that hints at its content. ~16px to 20px, stroke-based.

| Stage | Glyph |
|---|---|
| 0 — Play | a flat speaker shape |
| 1 — Pulse | a heart outline pulsing |
| 2 — Hats + clap | two hands clapping |
| 3 — Clave | two sticks crossed |
| 4 — Counting | a number "4" in a circle |
| 5 — Low end | a sine wave dipping low |
| 6 — Colour | overlapping circles like Venn |
| 7 — Shape | a rising-then-falling line |
| 8 — Play it out | two records side by side |

Visible on the home tree next to each stage heading. Tiny. Not loud.

## Page-level moves

- **Home**: bigger optical title. Subtitle italic Fraunces. Stage rows get tiny glyph + larger spacing. Per-stage progress bar replaces `[N/T]` number where space allows; keeps the number as fallback.
- **Lessons index**: cards with format-badge colour (cultural-deep-dive = terracotta, concept-across-cultures = teal). Card hover lifts 2px.
- **Toy page**: notebook-paper feel — a soft horizontal rule line per `<section>`, slightly off-axis subtitle. Code block stays high-contrast.
- **Review page**: little "due plant" sketch growing per item that needs review. Empty state: mascot napping.

## What stays

- Skip-to-content link.
- Reduce-motion media query.
- Single nav (DropdownNav). No second horizontal nav.
- Bottom playground bar at the bottom of every page.
- Plain-language copy.
