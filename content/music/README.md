# music

Learning to make house music by writing code (Strudel), plus the listening, music
theory, and DJ skills underneath it. Built for an absolute beginner. Plain
language, small steps.

## Start here

Open `learning-journey.md`. That is the path. Everything else supports it.

## The files

- `learning-journey.md`: the path. Stages 0 to 7. What to do, in order, with code. **Start here.**
- `strudel-cheatsheet.md`: quick code lookup. Drum names, symbols, snippets to paste.
- `resources.md`: the tutorial pile. Free and open-license links, sorted by topic, with a "best for you" flag.
- `practice-log-template.md`: copy this each session to track what you did. Keeps the habit visible.

## The one-line idea

Hear it first. Make it in code. Name it after. Keep sessions short. Build something every time.

## Tools you will use (all free)

- **Strudel** (strudel.cc): write code, hear music, in the browser. No install. Open source, AGPL-3.0.
- **Mixxx** (mixxx.org): free open-source DJ software, for the DJ stages. Open source, GPLv2.
